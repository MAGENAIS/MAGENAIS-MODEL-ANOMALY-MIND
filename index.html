magenais.anomaly-mind · v1.0.0

Lightweight, explainable anomaly detection.

Flags outliers in tabular or time-series data using simple, well-understood statistics — no neural network — then reports an Anomaly Context Stability score for whether each flag holds up under different thresholds, windows, methods, and row subsets, or only under one specific setting.

What it does

Given a table of records, AnomalyMind infers which columns are numeric, scores every present value using one of four methods — median absolute deviation (MAD), robust (modified) Z-score, interquartile range (IQR), or rolling local-neighborhood statistics — and flags a value anomalous when its deviation exceeds the method's threshold.

For every flag, it computes an Anomaly Context Stability (ACS) score: the proportion of tested configurations — varying threshold, window, method, and a resampled row subset — under which the same observation stays flagged. It is a research-oriented model: MAD/Z-score/IQR/rolling are well-established statistics; ACS is this model's own framing of configuration-resampling stability on top of them, not a claim of a new detection algorithm. See docs/algorithm.md for the full method.

Limitations

  • Only univariate anomalies are modeled — no multivariate outlier detection (e.g. Mahalanobis distance) in v1.0.0.
  • The rolling method's fixed-size window has fewer neighbors near the start/end of a series, which can make edge observations more sensitive to being flagged under that method alone.
  • ACS's "normalization" variation cycles through this model's own four methods, not arbitrary data transforms.
